# NoteDown

A cross-platform notes app — currently in the concept phase.

Right now this repository holds requirements and clickable HTML mockups
that work out what NoteDown does and how it is operated on desktop,
tablet and phone. App code comes later.

## Where to look

- [`docs/requirements.md`](docs/requirements.md) — the decided scope.
- [`docs/interaction-concept.md`](docs/interaction-concept.md) — how the
  app is operated across devices.
- [`mockups/`](mockups/) — open any `.html` file directly in a browser;
  resize the window (or use the browser's device mode) to see the tablet
  and phone layouts.
- [`FEATURE_BACKLOG.md`](FEATURE_BACKLOG.md) — ideas not yet decided.
