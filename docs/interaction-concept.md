# Interaction concept (Bedienkonzept)

Cross-cutting rules for how NoteDown is operated, independent of a single
feature: navigation structure, how the layout adapts per device tier
(`PROJECT.md` → "Device tiers"), touch gestures, keyboard shortcuts,
selection, undo, and the visual language (tokens in
`mockups/shared/tokens.css`). Feature-specific behavior stays in
`docs/requirements.md`; a rule moves here once a second feature needs it.

Current state, edited in place when a decision changes; each rule carries
one line of reason.
