# Contributing to NoteDown

NoteDown is a one-person project in its concept phase. Contributions are
welcome, but please **open an issue first** and wait for an answer before
you write code: the requirements and the prototype change quickly, and a
change that isn't planned may not fit.

- **License:** NoteDown is licensed under the GNU Affero General Public
  License, version 3 or later (`LICENSE`). By sending a contribution you
  agree that it is published under the same license.
- **Contributor agreement:** none for now. Whether one is needed (for
  example to keep the option of offering NoteDown under another license)
  is decided before the first contribution from someone else is merged.
- **How the project works:** `PROJECT.md` describes the layout,
  `CLAUDE.md` the rules every change follows (English in code and docs,
  Conventional Commit prefixes, tests with every change to the core
  logic).
